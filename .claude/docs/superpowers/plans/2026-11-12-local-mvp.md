# 로컬 시연 구현 계획

목표는 승인된 로컬 MVP 설계에 따라 Next.js와 SQLite를 연결하고 gpt-5.4-mini로 초안, 번역, 답변 판단을 실행하는 것이다.

- 서버는 SQLite에 검수한 미리보기를 저장하고 발행 ID로 영어 화면만 조회한다. 중복 발행, 재시작, 세션별 응답과 재시도를 테스트한다.
- OpenAI Responses 호출을 구조화하고 공지 근거와 판단 상태를 검증한다. 모호한 답과 부족한 원문 근거를 구분한다.
- 관리자와 작업자 화면을 구축하고 API 경계에서 입력을 확인한다. 원문이나 초안 변경 시 이전 미리보기를 무효화한다.
- 단위 테스트, 프로덕션 빌드, 로컬 HTTP 시연을 수행한다. API 키가 필요한 실제 호출은 별도로 확인한다.
