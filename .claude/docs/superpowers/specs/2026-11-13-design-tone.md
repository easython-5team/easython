# 디자인 톤: Field Note Pop

시안: 톤 보드 아티팩트 (B 다크 히어로 + A 컬러 버블 조합 채택)

## 원칙

- 색은 장식이 아니라 의미다. 다섯 가지 조건 유형과 확인 상태에 색을 하나씩 대응한다.
- 테두리 대신 색 면과 옅은 그림자로 구분한다.
- 작업자 화면은 톤을 강하게, 관리자 화면은 같은 토큰을 차분하게 쓴다.

## 토큰 (Tailwind `@theme`, `app/globals.css`)

| 토큰 | 값 | 의미 |
| --- | --- | --- |
| `canvas` | `#EDE7DD` (격자 없음) | 페이지 배경 |
| `paper` | `#FBF8F3` | 기본 카드, 시트 |
| `ink` | `#121212` | 제목, 주 버튼, 다크 히어로 |

## 글자

Pretendard. 화면 제목 900 / 자간 -0.06em, 핵심 문장 700 / -0.045em, 본문 400 / 16px 이상, 라벨 700 / 12px.

## 모양

카드 라운드 28–30px, 버튼·칩·태그는 알약(999px). 주 버튼은 검정 알약, 보조 버튼은 흰 바탕에 검정 1.5px 안쪽 선.

## 작업자 화면

한 화면에 한 가지 일만 둔다. 상단 진행 표시(읽기 · 답하기 · 확인)로 위치를 알려 준다. 읽기 단계에는 공지와 "다 읽었어요" 버튼만, 답하기 단계에는 상황 질문·대화·입력창만 보인다. 답한 기록이 있는 작업자는 답하기 단계로 바로 들어간다.

1. **다크 히어로**: 검정 배경에 공지를 한 문장으로 요약. 핵심 단어만 흰 글자, 나머지는 회색. 장소·행동은 색 알약 태그.
2. **조건 시트**: 위가 둥근 종이 시트가 올라오고, 바뀐 조건을 색 원형 아이콘 + 두 줄 텍스트로 나열.
3. **대화**: 작업자 답변은 검정 말풍선, AI 판정은 상태 색 말풍선(이해함 초록, 되묻는 중 주황, 오해 코랄), 관리자 답변은 라벤더 말풍선.
4. **입력**: 하단에 떠 있는 흰 알약 입력창 + 검정 보내기 버튼.
5. 언어 선택은 큰 색 블록 버튼.

## 관리자 화면

캔버스 위에 `paper` 카드. 색은 조건 칩, 상태 배지, 통계 카드의 상태 점, 스테퍼의 현재 단계에만 쓴다. 미리보기 폰 안은 작업자 톤 그대로.
