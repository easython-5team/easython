# 외국인 근로자 작업 지시 이해 지원 서비스 기획안

## 1. 문제 상황

외국인 노동자가 국내 제조업이나 건설 현장에서 일할 때, 관리자와 작업자가 사용하는 언어가 달라 작업 지시나 안전수칙을 서로 다르게 이해하는 문제가 생길 수 있다. 특히 익숙한 작업 방침이 갑자기 바뀌면 작업자는 **무엇이 바뀌었는지, 언제부터 어떤 작업에 적용해야 하는지**를 함께 파악해야 한다.

예를 들어 건설 현장에서 강풍이 예상돼 관리자가 “오후 2시부터 옥상 작업을 모두 중단한다. 공구와 남은 자재는 옥상에 두고 내려온다”라고 공지했다고 가정한다. 평소에는 공구와 자재를 정리해야 작업이 끝나기 때문에, 작업자는 설치 작업만 멈추고 공구는 챙겨 내려가야 한다고 이해할 수 있다. 이 경우 평소처럼 자재를 정리하다가 강풍에 날린 자재에 맞을 위험이 있다. 관리자는 작업자가 공지를 읽었다는 사실은 확인할 수 있지만, **작업자에게 ‘작업 중단’이 정리까지 멈추라는 뜻으로 전달됐는지**는 알기 어렵다.

국내 조사에서도 작업 지시의 오해가 생산과 안전에 영향을 준다는 응답이 나타났다.

- **생산 차질과 위험 상황.** 중소기업중앙회의 2025년 조사에서 전체 응답 기업 1,223곳 중 637곳이 외국인 근로자와의 의사소통에 어려움이 있다고 답했다. **이 637곳 중 63.9%는 작업 지시 오해로 인한 생산 차질을, 9.4%는 안전사고 발생 또는 위험 상황을 꼽았다.** [중소기업중앙회 실태조사, 표 4·5](https://www.kbiz.or.kr/download.do?fleDwnDs=bbsAttachFile&orgalFle=ebb3b4eb8f84332d28ebb699ec9e8429eca1b0ec82ac20eab2b0eab3bcebb3b4eab3a0ec849c2e706466&saveFle=176795066914291125.pdf&seq=89598)
- **작업자가 경험한 언어 장벽.** 국내 조선·제조·농업 분야에서 일하는 외국인 노동자 52명을 조사한 연구에서는 **응답자의 65.4%가 안전 관련 의사소통을 어렵게 하는 요인으로 언어를 꼽았다.** [한국안전문화학회 연구](https://www.kci.go.kr/kciportal/ci/sereArticleSearch/ciSereArtiView.kci?sereArticleSearchBean.artiId=ART003308648)

> 📌 우리 팀은 **변경 공지를 읽은 작업자가 새 방침을 자신의 작업에 적용하는 과정에서 생기는 오해에 집중**한다.

## 2. 솔루션

관리자가 작업 방침 변경을 공지하면, **AI가 ‘평소와 달리 지금 무엇을 해야 하는지’를 작업자의 언어로 설명한다.** 작업자는 상황 질문 한 개에 답하면서 핵심 지시를 확인하고, 자신의 상황이 선택지에 없으면 직접 질문할 수 있다.

1. **관리자가 평소처럼 공지를 작성한다.** AI는 원문에서 달라진 행동과 적용 시점, 놓치기 쉬운 조건을 추려 번역한다. 옥상 작업 사례에서는 ‘오후 2시부터 옥상 작업 중단’과 ‘공구·자재 정리도 중단’이라는 두 내용을 함께 보여준다.

2. **AI가 주관식 상황 질문 한 개를 만들고, 관리자가 검수한다.** 관리자는 작업자 화면 미리보기에서 변경 사항, 질문, 판단 근거가 되는 원문을 함께 확인한다. 예를 들어 “몇 시부터 작업을 중단하는가?”라는 질문을 “오후 2시에 옥상에 공구가 남아 있다면 어떻게 하겠는가?”로 수정할 수 있다. 검수가 끝나면 확정된 공지와 질문을 작업자의 언어로 번역해 발행하고, 단체톡 링크나 현장 QR로 공유한다.

3. **작업자가 자기 언어로 공지를 읽고, 자신이 할 행동을 한 문장으로 설명한다.** 같은 입력창에 “공구를 두고 바로 내려간다”라고 답할 수도 있고, “정리하던 공구도 그대로 두고 내려가야 하나?”라고 되물을 수도 있다.

4. **AI가 작업자의 답변을 공지와 대조한다.** “공구를 두고 바로 내려간다”처럼 행동이 지시와 일치하면 확인을 마친다. “공구만 챙기고 내려간다”라고 답하면 ‘공구와 남은 자재는 옥상에 두고 내려온다’는 근거 문장을 보여주고, 정리까지 중단한다는 점을 다시 설명한다. “내려간다”처럼 공구를 어떻게 할지 드러나지 않은 답에는 “남아 있는 공구는 어떻게 할 건가?”라고 한 번 더 묻는다.

5. **공지에 판단 근거가 없으면 관리자에게 확인을 요청한다.** 예를 들어 작업자가 “내일 아침에는 옥상 작업을 다시 시작해도 되나?”라고 물었는데 재개 시점이 공지에 없다면, 관리자에게 질문 원문과 한국어 번역을 전달한다. 관리자가 확정한 답은 작업자의 언어로 전달하고, 같은 공지에 반영해 다른 작업자도 확인할 수 있게 한다.

하루짜리 해커톤의 기본 구현 범위는 **공지 작성·검수 → 번역·발행 → 모국어 한 문장 응답 → 공지에 근거한 재설명 또는 관리자 확인 요청 → 확정 답변 반영**이다.

시연에서는 작업자용 언어를 한 가지로 고정하고, 답변과 질문은 텍스트로 입력한다. 음성 입력은 선택 기능으로 둔다.

### 관리자용과 작업자용 화면의 분리

| 관리자 화면 | 작업자 화면 |
| --- | --- |
| 1. 변경된 작업 방침을 한국어로 입력한다. | 1. 공유 링크나 현장 QR로 공지를 연다. |
| 2. 작업자 화면 미리보기에서 변경 사항, 상황 질문, 근거 문장을 검토하고 필요하면 `[수정]`한다. | 2. 자기 언어로 무엇이 바뀌었고 지금 어떻게 행동해야 하는지 읽는다. |
| 3. `[발행]`을 누르고 링크나 QR을 공유한다. | 3. 상황 질문에 자기 말로 답하거나 같은 입력창에서 되묻는다. |
| 4. 확인 요청이 들어오면 한국어로 답하고, 공지에 추가할 지시를 확정한다. | 4. 공지에 근거한 설명을 확인한다. 관리자 판단이 필요한 질문은 답변이 등록되면 자기 언어로 확인한다. |

**관리자에게 우선 필요한 기능은 ‘작업자 화면 미리보기’다.** 예를 들어 공지에는 ‘옥상 작업 중단’이라고 썼는데 AI가 만든 질문은 ‘몇 시에 중단하는가?’만 물을 수 있다. 관리자가 발행 전에 이를 보면, 실제로 확인하려는 ‘공구 정리까지 멈춰야 하는가?’로 질문을 고칠 수 있다.

- AI가 작업 현장의 상황을 100% 이해할 수 없으니 관리자가 초안 및 질문을 검수할 수 있게 하겠다는 뜻!
- 별도 챗봇까지는 필요없고, 미리보기 화면에 **`[수정]`**과 **`[발행]`** 버튼 정도만 두면 될 듯.

## 3. 기대 효과와 한계

### 기대 효과

- **평소와 달라진 행동을 분명하게 전달한다.** 작업자는 변경 시점과 적용 범위를 자기 언어로 확인한다. 예를 들어 ‘오후 2시부터 옥상 작업 중단’이라는 공지에서 **공구 정리까지 멈춰야 한다**는 점을 구체적으로 파악할 수 있다.
- **작업 전에 오해를 발견하고 바로잡을 기회를 만든다.** 작업자가 ‘공구를 정리한 뒤 내려간다’를 선택하면, 공지 전체를 다시 읽게 하는 대신 놓친 조건을 짚어 설명한다. 관리자도 어떤 부분에 추가 설명이 필요한지 파악할 수 있다.

### 한계

- **즉시 행동해야 하는 상황에서는 사용할 시간이 부족하다.** 검수·열람·응답에 시간이 걸리므로, 서비스가 가장 적합한 시점은 **변경된 방침에 따라 작업을 시작하기 전**이다. 이미 위험이 발생한 순간에는 현장 경보와 직접 대피 지시가 우선이다.
- **현장 상황과 실제 행동을 모두 확인할 수는 없다.** AI는 공지에 빠진 위험 요소나 예외 조건을 스스로 알기 어려워 관리자의 검수가 필요하다. 작업자가 정답을 골라도 현장에서 그대로 행동했는지까지는 알 수 없다. 따라서 이번 해커톤에서 제시할 효과는 **작업 지시의 오해를 발견하고 재설명할 수 있다는 점**이며, 실제 사고 감소 효과는 현장 검증이 필요하다.
