# 로컬 데모 모드 QA 가이드

데모 모드는 팀원이 OpenAI API 키 없이 관리자·작업자 화면을 테스트하고 디자인을 수정할 때 사용한다. 자재 반입 공지의 퀴즈, 영어 번역, 되묻기는 미리 준비된 예시로 동작한다. 공지 발행, 링크 복사, 번역 캐시, 작업자 대화 기록은 실제 앱과 같은 흐름을 거치며 데모 데이터는 `data/easython-demo.db`에 저장된다.

## 실행

Node.js 24 이상에서 프로젝트 폴더를 열고 다음 명령을 실행한다. `npm ci`는 처음 설치하거나 의존성이 바뀌었을 때 실행하면 된다. 별도의 환경 변수 설정은 필요 없다.

```sh
npm ci
npm run demo
```

Windows PowerShell에서 npm 실행이 제한되면 `npm.cmd ci`, `npm.cmd run demo`를 사용한다. [로컬 관리자 화면](http://127.0.0.1:3102/)에서 **로컬 데모** 표시와 **[내일 오전 1층 자재 반입 장소 변경 안내]** 제목을 확인한다. 화면을 수정하는 동안 서버를 켜 두면 변경 사항이 반영된다. 종료하려면 실행한 터미널에서 `Ctrl+C`를 누른다.

## 퀴즈 생성부터 되묻기까지

1. 미리 입력된 공지에서 **퀴즈 생성**을 누른다. **이해 확인 퀴즈**에 오전 9시 자재의 반입 출입구와 하역 장소를 묻는 질문이 나와야 한다. **답변에서 확인할 내용**과 **원문 근거 보기**를 확인한다.
2. 첫 시연에서는 기본 퀴즈 그대로 **공지 발행 → 공지 링크 복사**를 누른다. 복사한 링크를 같은 컴퓨터의 새 탭에서 연다. PC 카카오톡으로 시연할 때도 서버를 실행한 컴퓨터에서 링크를 클릭한다.
3. 작업자 화면에서 **English**를 선택한다. 영어 공지와 퀴즈가 표시되면 아래 문장을 한 번에 하나씩 보낸다.

| 순서 | 붙여넣을 답변 | 기대 결과 |
| --- | --- | --- |
| 첫 답변 | `I'll use the west entrance.` | 출입구만 답했으므로 **One more question**과 함께 “Where exactly will you leave the materials?”가 뜬다. |
| 후속 답변 | `In the yellow marked area in front of the first-floor materials room.` | 앞뒤 답변을 합쳐 **Understanding confirmed**가 뜨고 대화가 끝난다. |

## 추가로 확인할 화면

- **두 번째 답변도 모호할 때** — 같은 공지 링크를 새 탭에서 열어 위 첫 답변을 보내고, 후속 질문에 `I'm not sure.`라고 답한다. **Action to follow**와 영어 공지가 표시되고 대화가 끝난다.
- **관리자가 퀴즈를 수정했을 때** — 관리자 화면에서 질문이나 판단 기준을 바꾸고 발행한다. 새 링크에서는 수정한 질문이 입력한 언어 그대로 표시된다. 기본 예시와 다른 질문이나 판단 기준에 답변을 제출하면 **Manager confirmation needed**가 뜬다.
- **다른 원문으로 생성을 시도했을 때** — 원문을 바꾸고 **퀴즈 생성**을 누르면 예시를 선택하라는 안내가 뜬다. **예시 불러오기**로 자재 반입 공지를 복원할 수 있다.

데모는 정해진 영어 문장을 인식하므로 자유로운 표현의 의미를 판단하는 능력이나 번역 품질은 일반 모드에서 확인한다. 일반 모드의 키 설정과 실행 방법은 [README의 로컬 시연 안내](../README.md#로컬-시연)를 참고한다.
