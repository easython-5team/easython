# 로컬 데모 모드 QA 가이드

데모 모드는 OpenAI API 키 없이 전체 유저 플로우를 리허설할 때 사용한다. AI 분석·번역·판정은 **강풍 옥상 작업 중단** 예시에 맞춘 스크립트로 동작하고, 저장·발행·QR·세션·관리자 확인 요청·공지 버전 반영은 실제 기능을 사용한다. 데이터는 `data/fieldnote-demo.db`에 저장된다.

```sh
npm ci
npm run demo   # http://127.0.0.1:3102
```

## 1. 관리자 · 공지 준비

1. 미리 입력된 공지에서 **AI로 변경 조건 분석**을 누른다. 조건 5개(시점·행동·금지·행동·장소)와 원문 하이라이트, 상황 질문, “AI가 이 질문을 만든 이유”가 보인다. 3번(금지)과 4번(행동)이 `답변에서 확인`으로 체크되어 있다.
2. **작업자 화면 미리보기**를 누르면 휴대폰 미리보기(EN/VI 탭)와 조건별 **번역 의미 검증** 표, 역번역 전문이 나온다.
3. **승인하고 발행 · QR 만들기** → 대시보드로 이동한다. QR, 링크 복사, 현장 게시용 QR(인쇄)을 확인한다.

조건 문장이나 질문을 수정하면 데모는 수정 문장을 번역하지 못하므로 검증 표에 `확인 필요`가 뜨고, 경고 확인 체크 없이는 발행되지 않는다(의도된 동작).

## 2. 작업자 · 이해 확인 (각각 새 시크릿 창 또는 다른 브라우저)

작업자 화면은 **읽기 → 답하기 → 확인** 세 단계로 나뉜다. 언어와 이름을 입력하면 공지(읽기)만 보이고, **I have read it / Tôi đã đọc xong**을 눌러야 상황 질문과 입력창(답하기)이 나온다. 답하기 화면의 **Read the notice again / Đọc lại thông báo**로 공지를 다시 볼 수 있고, 이미 한 답은 유지된다.

| 작업자 | 언어 | 입력 | 기대 결과 |
| --- | --- | --- | --- |
| Anna | English | `I'll go downstairs.` | **One more question** — 4번 ✓, 3번 ? / “What will you do with the tools you are using?” |
| Anna | | `I'll leave them there.` | **Understanding confirmed** — 두 조건 ✓ |
| Minh | Tiếng Việt | `Tôi sẽ mang dụng cụ theo rồi đi xuống.` | **Vui lòng làm theo hướng dẫn này** — 3번 ✕(충돌), 근거 조건 재설명 |
| Lan | Tiếng Việt | `Sáng mai có được làm lại không?` | **Đã gửi cho quản lý** — 관리자 답변 대기 표시 |

- 공지·질문·판정 결과마다 **Listen / Nghe** 버튼으로 TTS를 재생할 수 있다(기기에 해당 언어 음성이 없으면 안내가 뜬다).
- **Speak / Nói**로 말하면 인식 문장이 입력창에 들어가고, 확인·수정 후 직접 보낸다. Chrome 권장, 휴대폰에서는 HTTPS 주소가 필요하다.
- 같은 휴대폰에서 링크를 다시 열면 대화가 이어진다. 이미 답한 적이 있으면 읽기 단계를 건너뛰고 답하기 화면으로 바로 들어간다.

## 3. 관리자 · 예외 처리

1. 대시보드(3초마다 자동 갱신)에서 통계, 작업자별 상태와 조건 칩, 한국어로 번역된 최근 답변을 확인한다. 작업자 이름을 누르면 턴별 판정 근거(작업자 발화 인용)가 보인다.
2. **관리자 확인 요청**에서 Lan의 질문(한국어 번역 + 원문)을 확인하고 **데모 답변 넣기 → 답변 확정**을 누른다.
3. Lan 화면에 몇 초 안에 베트남어 관리자 답변이 나타나고, 공지가 v2로 올라가 “Quản lý bổ sung” 섹션이 생긴다.
4. 새 작업자가 English로 `Can we restart tomorrow morning?`라고 물으면 이번에는 관리자에게 넘기지 않고 v2 공지로 답한다.

데모는 정해진 문장만 인식하므로 자유 표현 판정과 번역 품질은 일반 모드(`npm run dev` + `OPENAI_API_KEY`)에서 확인한다.
