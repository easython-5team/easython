# 이해 확인 퀴즈 기준

## 현재 MVP의 난이도

**적용형 한 문제**로 고정한다. 작업자가 공지를 암기했는지보다 바뀐 행동을 자기 상황에 적용하는지 확인하기 위한 선택이다. 예를 들어 “공사는 몇 시에 시작하나요?” 대신 “오전 9시에 자재가 도착하면 어느 출입구로 가져가고 어디에 놓나요?”를 묻는다.

## 생성·검수 규칙

1. 원문에 명시된 변경 행동과 적용 시간·장소·조건을 토대로 한 가지 상황을 제시한다. 원문에 없는 안전 절차나 예외를 만들지 않는다.
2. 질문은 주관식으로 작성한다. 예·아니요, 시간만 맞히는 문제, 질문 안에 정답이 들어 있는 문제는 피한다.
3. 판단 기준에는 관찰 가능한 행동을 적는다. 원문에 두 가지 필수 행동이 있으면 둘 다 포함한다. 현재 자재 반입 예시에서는 **서쪽 출입구 이용**과 **노란 표시 구역에 하역**이 필수다.
4. 관리자는 AI가 제시한 원문 근거, 상황 질문, 판단 기준을 함께 검수한다. 검수 확인 뒤에만 작업자 화면 미리보기를 생성한다.
5. 답변에서 필요한 행동 하나가 빠졌으면 한 번만 되묻는다. 명백히 반대되는 행동은 공지에 근거해 바로잡는다. 원문에 없는 정보는 정답으로 추정하지 않고 관리자 확인 필요로 처리한다.

난이도를 여러 단계로 늘릴 때는 각 단계의 통과 기준과 오답 사례를 먼저 수집해야 한다. 현재는 현장 사용자 검증 없이 어려운 질문을 늘려 작업자를 평가하는 방향으로 확장하지 않는다.
